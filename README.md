# ParkEase AI - Find. Park. Pay. Go.

A complete product, UX, architecture, implementation and demo specification for a 24-hour college hackathon MVP.

## Quick Start

### Backend (Python FastAPI)
```bash
cd backend
pip install -r requirements.txt
uvicorn main:app --reload --port 8000
```

### Frontend (React + Vite + TypeScript)
```bash
cd frontend
npm install
npm run dev
```

Open http://localhost:5173 to access the full application.
